Limits & Continuity

What Is a Limit?

+

A limit describes the value a function approaches as the input approaches some value — not necessarily what the function equals there.

\lim_{x \to c} f(x) = L

Formal epsilon-delta definition: for every \(\varepsilon > 0\) there exists \(\delta > 0\) such that \(0 < |x - c| < \delta \Rightarrow |f(x) - L| < \varepsilon\).

◈
Key InsightThe limit describes behavior as \(x \to c\), completely ignoring the value at \(c\). The function doesn't even need to be defined at \(c\).
Limit Visualization
c = 1.0
The red dot shows the point being approached; the open circle shows the actual function value may differ.

Limit laws — if \(\lim_{x\to c} f(x) = L\) and \(\lim_{x\to c} g(x) = M\):

Limit Laws
\lim[f \pm g] = L \pm MSum / Difference
\lim[f \cdot g] = LMProduct
\lim[f/g] = L/M,\; M\neq 0Quotient
\lim[f^n] = L^nPower
\lim[k \cdot f] = kLScalar multiple

One-Sided Limits

+
Left-hand limit
\lim_{x \to c^-} f(x) = L
Right-hand limit
\lim_{x \to c^+} f(x) = L
★
Two-sided limit exists IFF both one-sided limits exist and are equal.\(\lim_{x\to c^-}f = \lim_{x\to c^+}f = L\)

Squeeze Theorem

If \(g(x) \le f(x) \le h(x)\) near \(c\), and \(\lim g = \lim h = L\), then \(\lim f = L\).

g(x) \le f(x) \le h(x) \;\text{and}\; \lim g = \lim h = L \;\Rightarrow\; \lim f = L
✓
Classic example: \(\lim_{x\to 0} x^2\sin(1/x) = 0\) since \(-x^2 \le x^2\sin(1/x) \le x^2\).

Special Trig Limits

+
★
Memorize these cold — they appear constantly.
\lim_{x \to 0} \frac{\sin x}{x} = 1
\lim_{x \to 0} \frac{1 - \cos x}{x} = 0
\lim_{x \to 0} \frac{1 - \cos x}{x^2} = \frac{1}{2}

For scaled versions: \(\displaystyle\lim_{x\to 0}\frac{\sin(5x)}{x} = 5\cdot\lim\frac{\sin(5x)}{5x} = 5\cdot 1 = 5\)

Indeterminate Forms

+

These cannot be evaluated by direct substitution — they require algebraic manipulation or L'Hôpital's Rule.

FormResolution Strategy
\(0/0\)Factor & cancel, rationalize, or L'Hôpital
\(\infty/\infty\)L'Hôpital, or divide by highest power
\(0 \cdot \infty\)Rewrite as \(0/(1/\infty)\) then L'Hôpital
\(\infty - \infty\)Combine fractions or factor
\(1^\infty\)Take ln, apply L'Hôpital, exponentiate
\(0^0\)Take ln, apply L'Hôpital, exponentiate
\(\infty^0\)Take ln, apply L'Hôpital, exponentiate

Continuity & IVT

+

\(f\) is continuous at \(x=c\) iff all three conditions hold:

  • \(f(c)\) is defined
  • \(\lim_{x\to c} f(x)\) exists
  • \(\lim_{x\to c} f(x) = f(c)\)

Types of Discontinuities

TypeCauseFixable?
Removable (hole)Limit exists but ≠ f(c)Yes — redefine f(c)
JumpLeft ≠ right one-sided limitNo
InfiniteLimit = ±∞ (VA)No
Oscillatinge.g. sin(1/x) at 0No

Intermediate Value Theorem (IVT)

If \(f\) is continuous on \([a,b]\) and \(N\) is between \(f(a)\) and \(f(b)\), then \(\exists c \in (a,b)\) with \(f(c)=N\).

f \text{ cont. on } [a,b],\; f(a) < N < f(b) \;\Rightarrow\; \exists c \in (a,b): f(c)=N
✓
To prove a root exists: show f is continuous and f(a), f(b) have opposite signs — then IVT guarantees a zero.

Differentiation — Definitions & Rules

Definition of the Derivative

+

The derivative is the instantaneous rate of change — geometrically, the slope of the tangent line.

f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}
f'(a) = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}
Tangent Line — Moving Secant
x = 0.5
h = 1.0
Blue = function, orange = secant line, red = tangent line. As h→0, the secant approaches the tangent.
⚠
Non-differentiable points: corners (different slopes from left/right), cusps (slopes → ±∞ from opposite sides), vertical tangents, and any discontinuity.

All Derivative Rules

+
Basic Rules
\frac{d}{dx}[c] = 0Constant
\frac{d}{dx}[x^n] = nx^{n-1}Power (all real n)
\frac{d}{dx}[cf] = cf'Constant multiple
\frac{d}{dx}[f\pm g] = f' \pm g'Sum/difference
Product & Quotient
\frac{d}{dx}[fg] = f'g + fg'Product rule
\frac{d}{dx}\!\left[\frac{f}{g}\right] = \frac{f'g - fg'}{g^2}Quotient rule (lo·d(hi) − hi·d(lo), over lo²)
\frac{d}{dx}[f(g(x))] = f'(g(x)) \cdot g'(x)
★
Chain Rule — the most-used rule on the exam. Every function with something "inside" uses it. Derivative of outside, keep inside, times derivative of inside.

Trig Derivatives — All 6

+
sin
\frac{d}{dx}\sin x = \cos x
cos
\frac{d}{dx}\cos x = -\sin x
tan
\frac{d}{dx}\tan x = \sec^2 x
cot
\frac{d}{dx}\cot x = -\csc^2 x
sec
\frac{d}{dx}\sec x = \sec x\tan x
csc
\frac{d}{dx}\csc x = -\csc x\cot x
⚠
cot, csc, cos — the "co-" functions all have negative derivatives. Don't forget the negatives.

Exponential & Log Derivatives

+
Natural exp
\frac{d}{dx}e^x = e^x
General exp
\frac{d}{dx}a^x = a^x\ln a
Natural log
\frac{d}{dx}\ln x = \frac{1}{x}
Log base a
\frac{d}{dx}\log_a x = \frac{1}{x\ln a}
✓
With chain rule: \(\frac{d}{dx}\ln(g(x)) = \frac{g'(x)}{g(x)}\). This is the key form for u-sub in integration.

Inverse Trig Derivatives — All 6

+
arcsin
\frac{d}{dx}\arcsin x = \frac{1}{\sqrt{1-x^2}}
arccos
\frac{d}{dx}\arccos x = \frac{-1}{\sqrt{1-x^2}}
arctan
\frac{d}{dx}\arctan x = \frac{1}{1+x^2}
arccot
\frac{d}{dx}\text{arccot}\, x = \frac{-1}{1+x^2}
arcsec
\frac{d}{dx}\text{arcsec}\, x = \frac{1}{|x|\sqrt{x^2-1}}
arccsc
\frac{d}{dx}\text{arccsc}\, x = \frac{-1}{|x|\sqrt{x^2-1}}
◈
Co-pairs (arccos/arcsin, arccot/arctan, arccsc/arcsec) are negatives of each other.

Advanced Differentiation

Implicit Differentiation

+

Use when \(y\) is not isolated. Differentiate both sides w.r.t. \(x\). Every time a term with \(y\) is differentiated, multiply by \(\frac{dy}{dx}\) (chain rule). Then solve for \(\frac{dy}{dx}\).

x^2 + y^2 = 25 \;\Rightarrow\; 2x + 2y\frac{dy}{dx} = 0 \;\Rightarrow\; \frac{dy}{dx} = -\frac{x}{y}
✓
Second implicit derivatives: differentiate dy/dx again w.r.t. x, then substitute the first dy/dx expression to eliminate it.

Derivatives of Inverse Functions

+

If \(f\) and \(g\) are inverses, then:

g'(x) = \frac{1}{f'(g(x))}

On the exam: if \(f(a) = b\), then \(g(b) = a\), so \(g'(b) = \dfrac{1}{f'(a)}\).

◈
Geometrically: the tangent slope of \(f^{-1}\) at \((b,a)\) is the reciprocal of the slope of \(f\) at \((a,b)\). The graphs are reflections across \(y=x\).

Logarithmic Differentiation

+

Used for \([f(x)]^{g(x)}\) — variable to a variable power. Take \(\ln\) of both sides, differentiate implicitly, solve for \(y'\).

y = f(x)^{g(x)} \;\Rightarrow\; \ln y = g(x)\ln f(x) \;\Rightarrow\; \frac{y'}{y} = g'\ln f + g\cdot\frac{f'}{f}
✓
Also useful for long products/quotients — taking ln converts multiplication to addition, making differentiation much cleaner.

Contextual Applications of Differentiation

Position, Velocity, Acceleration

+
Motion Relationships
v(t) = s'(t)Velocity = derivative of position
a(t) = v'(t) = s''(t)Acceleration = derivative of velocity
\text{speed} = |v(t)|Always non-negative
  • Particle speeds up when \(v(t)\) and \(a(t)\) have the same sign
  • Particle slows down when they have opposite signs
  • Displacement = \(\int_a^b v(t)\,dt\) (signed)
  • Total distance = \(\int_a^b |v(t)|\,dt\) (split at zeros of v)

Tangent Lines & Linear Approximation

+
y - f(a) = f'(a)(x - a)

Normal line (perpendicular to tangent): slope \(= -1/f'(a)\).

Linear Approximation (Linearization)

f(x) \approx f(a) + f'(a)(x-a) \;\text{ for } x \text{ near } a
★
Over/under-estimate: Concave up (f'' > 0) → tangent is BELOW curve → linearization underestimates. Concave down → tangent ABOVE → overestimates.

L'Hôpital's Rule

+

If a limit yields \(0/0\) or \(\infty/\infty\) after direct substitution:

\lim_{x\to c}\frac{f(x)}{g(x)} = \lim_{x\to c}\frac{f'(x)}{g'(x)} \quad \text{(when form is } 0/0 \text{ or } \infty/\infty\text{)}
⚠
L'Hôpital applies ONLY to \(0/0\) or \(\infty/\infty\). For other indeterminate forms (\(0\cdot\infty\), \(1^\infty\), etc.), algebraically rewrite first.
✓
After differentiating, re-check the form before applying again. You can apply repeatedly until you can substitute directly.

Related Rates

+

Both variables change with time. Differentiate a relating equation with respect to \(t\), then plug in known values.

  • Draw and label a diagram
  • Write an equation relating the variables
  • Differentiate both sides w.r.t. \(t\) (chain rule on every variable)
  • Substitute known rates and values
  • Solve for the unknown rate
\text{Ladder: } x^2 + y^2 = L^2 \;\Rightarrow\; 2x\frac{dx}{dt} + 2y\frac{dy}{dt} = 0

Analytical Applications of Differentiation

Mean Value Theorem & EVT

+

If \(f\) is continuous on \([a,b]\) and differentiable on \((a,b)\), then \(\exists c \in (a,b)\):

f'(c) = \frac{f(b)-f(a)}{b-a}
✓
FRQ justification: "Since f is continuous on [a,b] and differentiable on (a,b), by MVT there exists c in (a,b) such that f'(c) = [f(b)−f(a)]/(b−a)."

Extreme Value Theorem (EVT)

If \(f\) is continuous on a closed interval \([a,b]\), then \(f\) attains both a global max and min on \([a,b]\).

⚠
EVT requires closed interval and continuous function. No guarantee on open intervals.

Rolle's Theorem

Special case of MVT: if \(f(a)=f(b)\), then \(\exists c\) with \(f'(c)=0\).

Critical Points & Derivative Tests

+

A critical point is any \(x\) in the domain where \(f'(x)=0\) or \(f'(x)\) DNE.

First Derivative Test

  • \(f'\) changes \(+\to-\): local maximum
  • \(f'\) changes \(-\to+\): local minimum
  • \(f'\) doesn't change sign: neither

Second Derivative Test

When f'(c)=0
f''(c) > 0 \Rightarrow \text{local min}
When f'(c)=0
f''(c) < 0 \Rightarrow \text{local max}
⚠
If \(f''(c) = 0\), the second derivative test is inconclusive. Use the first derivative test instead.

For global extrema on \([a,b]\): evaluate \(f\) at all critical points in \((a,b)\) AND at both endpoints \(a\) and \(b\). Largest = global max; smallest = global min.

Concavity & Inflection Points

+
Concave Up
f''(x) > 0

Tangent line below curve

Concave Down
f''(x) < 0

Tangent line above curve

An inflection point is where concavity changes — \(f''\) changes sign. \(f''(c)=0\) is necessary but NOT sufficient.

⚠
\(f''(c)=0\) does NOT guarantee an inflection point. You must verify \(f''\) actually changes sign at \(c\).
Concavity Explorer
Blue shading = concave up (f''>0). Red shading = concave down (f''<0). Inflection points marked with ◆.

Optimization

+
  • Identify the quantity to maximize/minimize
  • Write it as a function of ONE variable (use constraint to eliminate others)
  • Find critical points in the domain
  • Verify with first or second derivative test
  • Check endpoints if domain is closed
✓
Always define variables and state the domain. Exam graders want to see explicit justification for why the critical point is a max or min.

Integration & Accumulation of Change

Riemann Sums

+
\sum_{i=1}^{n} f(x_i^*)\,\Delta x \;\xrightarrow{n\to\infty}\; \int_a^b f(x)\,dx
Riemann Sum Visualizer
n = 6
Approximating ∫ sin(x)+1.2 dx on [0, π]. Estimated area shown.
◈
If \(f\) is increasing: Left underestimates, Right overestimates. If decreasing: Left overestimates, Right underestimates. Trapezoid is more accurate than either.

Fundamental Theorem of Calculus

+

FTC Part 1 — Differentiation of Accumulation Functions

\frac{d}{dx}\int_a^x f(t)\,dt = f(x)
\frac{d}{dx}\int_a^{u(x)} f(t)\,dt = f(u(x))\cdot u'(x)
\frac{d}{dx}\int_{v(x)}^{u(x)} f(t)\,dt = f(u(x))\,u'(x) - f(v(x))\,v'(x)
✓
Plug the upper limit into f, multiply by the derivative of the upper limit. For a variable lower limit, subtract.

FTC Part 2 — Evaluation Theorem

\int_a^b f(x)\,dx = F(b) - F(a) \quad\text{where } F'=f
◈
The +C cancels when evaluating definite integrals, so you don't need it for F(b)−F(a).

All Antiderivative Rules

+
⚠
Always include +C on indefinite integrals. Missing it on an FRQ costs points.
Basic Antiderivatives
\int x^n\,dx = \frac{x^{n+1}}{n+1}+C,\; n\neq-1Reverse power rule
\int \frac{1}{x}\,dx = \ln|x|+CWorks for negative x
\int e^x\,dx = e^x+C
\int a^x\,dx = \frac{a^x}{\ln a}+C
\int \sin x\,dx = -\cos x+C
\int \cos x\,dx = \sin x+C
\int \sec^2 x\,dx = \tan x+C
\int \csc^2 x\,dx = -\cot x+C
\int \sec x\tan x\,dx = \sec x+C
\int \csc x\cot x\,dx = -\csc x+C
\int \frac{1}{\sqrt{1-x^2}}\,dx = \arcsin x+C
\int \frac{1}{1+x^2}\,dx = \arctan x+C

Integration Techniques

+

u-Substitution

\int f(g(x))\,g'(x)\,dx = F(g(x))+C

Let \(u = g(x)\), compute \(du = g'(x)\,dx\), substitute, integrate in \(u\), back-substitute.

✓
For definite integrals with u-sub: change the limits to u-values and don't back-substitute.

Integration by Parts

\int u\,dv = uv - \int v\,du

LIATE priority for choosing \(u\): Logarithm, Inverse trig, Algebraic, Trig, Exponential.

◈
Loop technique: when the original integral reappears (e.g. \(\int e^x\sin x\,dx\)), move it to the other side and divide: \(2I = \text{result} \Rightarrow I = \text{result}/2\).

Trig Substitution

FormSubstitutionResult
\(\sqrt{a^2-x^2}\)\(x = a\sin\theta\)\(\sqrt{} = a\cos\theta\)
\(\sqrt{a^2+x^2}\)\(x = a\tan\theta\)\(\sqrt{} = a\sec\theta\)
\(\sqrt{x^2-a^2}\)\(x = a\sec\theta\)\(\sqrt{} = a\tan\theta\)

Useful Trig Identities for Integration

\sin^2 x = \frac{1-\cos 2x}{2}
\cos^2 x = \frac{1+\cos 2x}{2}
1+\tan^2 x = \sec^2 x
\sin^2 x + \cos^2 x = 1

Improper Integrals

+
\int_a^{\infty} f(x)\,dx = \lim_{t\to\infty}\int_a^t f(x)\,dx
\int_{-\infty}^{\infty} f(x)\,dx = \int_{-\infty}^c f\,dx + \int_c^{\infty} f\,dx
★
p-series benchmark: \(\displaystyle\int_1^{\infty}\frac{1}{x^p}\,dx\) converges if \(p>1\), diverges if \(p\le 1\).

Differential Equations

Slope Fields

+

A slope field visualizes a DE by drawing a short segment at each point \((x,y)\) with slope \(= dy/dx\). Solution curves are tangent to every segment they pass through.

Slope Field Explorer
Click on the canvas to draw a solution curve through that point.

Separable Differential Equations

+

A DE is separable if it can be written as \(h(y)\,dy = g(x)\,dx\). Then integrate both sides.

\frac{dy}{dx} = \frac{g(x)}{h(y)} \;\Rightarrow\; \int h(y)\,dy = \int g(x)\,dx
✓
After solving, check your answer by differentiating and verifying it satisfies the original DE. Apply initial conditions to find C, then solve for y explicitly if possible.

Exponential Growth & Decay

The DE \(\frac{dy}{dt} = ky\) has the solution:

y = y_0 e^{kt}
  • \(k > 0\): exponential growth
  • \(k < 0\): exponential decay
  • Half-life: \(t_{1/2} = -\ln 2/k\)
  • Doubling time: \(t_d = \ln 2/k\)

Logistic Growth

+
\frac{dy}{dt} = ky\!\left(1 - \frac{y}{L}\right)
y(t) = \frac{L}{1+Ae^{-kt}}, \quad A = \frac{L-y_0}{y_0}
★
Growth is fastest at \(y = L/2\) — this is the inflection point of the S-curve. At \(y=L/2\), \(dy/dt\) is maximized.
  • \(y=0\) and \(y=L\) are equilibrium solutions
  • Population never exceeds \(L\) if it starts below \(L\)
  • \(L\) = carrying capacity
Logistic Growth Curve

Dashed line = carrying capacity L=100. Red dot = inflection point at y=L/2.

Euler's Method

+
y_{n+1} = y_n + F(x_n, y_n)\cdot\Delta x

Numerically approximates a solution by stepping along tangent lines from the initial point.

⚠
Concave up: Euler's method underestimates (tangent below curve). Concave down: overestimates. Smaller Δx → more accurate.

Applications of Integration

Area Between Curves

+
A = \int_a^b \bigl[f(x) - g(x)\bigr]\,dx \quad (f \ge g)
A = \int_c^d \bigl[R(y) - L(y)\bigr]\,dy \quad \text{(horizontal slices)}
✓
Always integrate [top − bottom] (or [right − left] for horizontal). Find intersection points by setting f(x) = g(x). Split into sub-integrals if the curves cross.
◈
Average value of \(f\) on \([a,b]\): \(\displaystyle\bar{f} = \frac{1}{b-a}\int_a^b f(x)\,dx\)

Volumes of Revolution & Cross Sections

+

Disk Method (no gap)

V = \pi\int_a^b [f(x)]^2\,dx

Washer Method (gap between two curves)

V = \pi\int_a^b \bigl([R(x)]^2 - [r(x)]^2\bigr)\,dx
✓
When rotating about \(y=k\), the radius from the axis to each curve is \(|f(x)-k|\) and \(|g(x)-k|\).

Shell Method

V = 2\pi\int_a^b x\cdot f(x)\,dx \quad \text{(about y-axis)}
V = 2\pi\int_a^b (x-k)\cdot f(x)\,dx \quad \text{(about }x=k\text{)}

Cross-Sectional Volumes

V = \int_a^b A(x)\,dx
Cross SectionArea A(x)
Square\([f(x)]^2\)
Semicircle\(\frac{\pi}{8}[f(x)]^2\)
Equilateral triangle\(\frac{\sqrt{3}}{4}[f(x)]^2\)
Isosceles right triangle\(\frac{1}{2}[f(x)]^2\)

Arc Length

+
L = \int_a^b \sqrt{1 + [f'(x)]^2}\,dx
L = \int_c^d \sqrt{1 + [g'(y)]^2}\,dy

Parametric, Polar & Vector-Valued Functions

Parametric Equations

+

A parametric curve is defined by \(x=f(t)\) and \(y=g(t)\).

Derivatives
\dfrac{dy}{dx} = \dfrac{dy/dt}{dx/dt}First derivative (slope)
\dfrac{d^2y}{dx^2} = \dfrac{\frac{d}{dt}\!\left(\frac{dy}{dx}\right)}{dx/dt}Second derivative
⚠
\(d^2y/dx^2 \ne (d^2y/dt^2)/(d^2x/dt^2)\). You must differentiate \(dy/dx\) with respect to \(t\), then divide by \(dx/dt\).
L = \int_a^b\sqrt{\!\left(\frac{dx}{dt}\right)^{\!2}+\left(\frac{dy}{dt}\right)^{\!2}}\,dt \quad \text{(arc length)}

Infinite Sequences & Series

Sequences & Series Basics

+

A sequence converges if \(\lim_{n\to\infty} a_n = L\) (finite). Growth rate hierarchy (slowest to fastest):

\ln n \ll n^p \ll a^n\;(a>1) \ll n! \ll n^n

Geometric Series

\sum_{n=0}^{\infty} ar^n = \frac{a}{1-r} \quad\text{if } |r|<1, \;\text{diverges if } |r|\ge 1
\sum_{n=0}^{N} ar^n = \frac{a(1-r^{N+1})}{1-r} \quad\text{(finite partial sum)}

nth Term Test (Divergence Test)

\lim_{n\to\infty} a_n \ne 0 \;\Rightarrow\; \sum a_n \text{ DIVERGES}
⚠
If \(\lim a_n = 0\), the test is inconclusive — the series may still diverge (harmonic series: \(\sum 1/n\) diverges).

L = \lim_{n\to\infty}\sqrt[n]{|a_n|}Root test
◈
Alternating Series Error Bound: \(|\text{error}| \le a_{N+1}\) (the first omitted term). The partial sum alternately over- and under-estimates the true sum.
◈
Absolute vs. Conditional: \(\sum|a_n|\) converges → absolutely convergent. Converges but \(\sum|a_n|\) diverges → conditionally convergent.

Power Series & Radius of Convergence

+
\sum_{n=0}^{\infty} c_n(x-a)^n = c_0 + c_1(x-a) + c_2(x-a)^2 + \cdots

Every power series has a radius of convergence \(R\). Converges absolutely for \(|x-a|R\). Check endpoints separately.

R = \frac{1}{\lim_{n\to\infty}|c_{n+1}/c_n|} \quad \text{(from Ratio Test)}
✓
Apply the Ratio Test to find R. Then plug in \(x = a \pm R\) separately and test each endpoint — the interval of convergence may be open, half-open, or closed at each end.

Taylor & Maclaurin Series

+
f(x) = \sum_{n=0}^{\infty}\frac{f^{(n)}(a)}{n!}(x-a)^n = f(a) + f'(a)(x-a) + \frac{f''(a)}{2!}(x-a)^2 + \cdots
★
Maclaurin = Taylor centered at \(a=0\). You must have these memorized.
eˣ
e^x = \sum_{n=0}^{\infty}\frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \frac{x^3}{3!}+\cdots
Converges for all x
sin(x)
\sin x = \sum_{n=0}^{\infty}\frac{(-1)^n x^{2n+1}}{(2n+1)!} = x - \frac{x^3}{3!}+\frac{x^5}{5!}-\cdots
Converges for all x
cos(x)
\cos x = \sum_{n=0}^{\infty}\frac{(-1)^n x^{2n}}{(2n)!} = 1 - \frac{x^2}{2!}+\frac{x^4}{4!}-\cdots
Converges for all x
1/(1−x) — geometric
\frac{1}{1-x} = \sum_{n=0}^{\infty} x^n = 1+x+x^2+x^3+\cdots
Converges for |x| < 1
ln(1+x)
\ln(1+x) = \sum_{n=1}^{\infty}\frac{(-1)^{n+1}x^n}{n} = x - \frac{x^2}{2}+\frac{x^3}{3}-\cdots
Converges for −1 < x ≤ 1
arctan(x)
\arctan x = \sum_{n=0}^{\infty}\frac{(-1)^n x^{2n+1}}{2n+1} = x - \frac{x^3}{3}+\frac{x^5}{5}-\cdots
Converges for |x| ≤ 1

Lagrange Error Bound

+
|R_n(x)| \le \frac{M\cdot|x-a|^{n+1}}{(n+1)!}

Where \(M\) = maximum of \(|f^{(n+1)}(t)|\) on the interval between \(a\) and \(x\).

  • For \(\sin x\) and \(\cos x\): all derivatives bounded by 1, so \(M=1\)
  • For \(e^x\): \(M = e^{|x|}\) (evaluate at the far endpoint)
✓
Process: find the (n+1)th derivative → bound it by M on your interval → plug into the formula. The bound must be LESS THAN the desired accuracy.
★

Exam Strategy & Common Mistakes

Top Mistakes to Avoid

+
  • Forgetting +C on indefinite integrals
  • Applying L'Hôpital when the limit isn't \(0/0\) or \(\infty/\infty\)
  • Claiming \(f''(c)=0\) means inflection without checking sign change
  • Missing the chain rule factor on \(e^{g(x)}\), \(\ln(g(x))\), trig of g(x)
  • Confusing displacement \(\int v\,dt\) with total distance \(\int|v|\,dt\)
  • Not checking endpoints for global extrema on closed intervals
  • Ratio test giving \(L=1\) → concluding convergence/divergence (it's inconclusive!)
  • Forgetting to test endpoints of interval of convergence separately
  • Using SDT when \(f''(c)=0\) — must use FDT
  • \(d^2y/dx^2\) for parametric: differentiating \(y''\) over \(x''\) instead of the correct formula
